Before you start

Three things, and one of them trips up most people.

  • A Chromium browser Chrome, Edge or Opera. Safari and Firefox cannot talk to serial ports.
  • A USB-C data cable Charge-only cables power the board but carry no data, so no port ever shows up. This is the single most common failure.
  • The board, plugged in Waveshare ESP32-S3-LCD-1.47B. Connect it before clicking Install.
The installer asks whether to erase the board first. Leave the box unchecked to keep your Wi-Fi credentials, channel mapping and audio levels; tick it for a clean slate. Your SD card is untouched either way — it is a separate device the installer never writes to.

After installing

The board has no network yet, so it hosts its own.

  1. Let it boot The screen runs through its checks, then shows the status display.
  2. Join ECHO_xxxx The board's own Wi-Fi network. Password 12345678. The last four characters come from its MAC address.
  3. Open 192.168.4.1 The console loads — dashboard, channels, audio, SD card, network, logs.
  4. Point it at your Wi-Fi Network page, then reboot. From then on it joins your network at startup.
Connect within 60 seconds. If nobody joins, the board shuts its Wi-Fi down to keep the radio quiet. Power-cycle to get it back.

If something goes wrong

Four failures cover almost everything.

No serial port in the list

Put the board into flashing mode by hand: hold BOOT, tap RESET, then release BOOT. Click Install again. If the list is still empty, the cable is charge-only — swap it before anything else.

The port is there but connecting fails

Something else already owns it. Close any serial monitor, Arduino IDE or PlatformIO session, then retry.

The install stops partway through

Usually the cable or a USB hub. Plug straight into the machine and try once more. A half-written flash is not fatal — the board stays in bootloader mode and you can start over.

No ECHO_xxxx network afterwards

Either the 60-second window has closed — power-cycle the board and look again — or the flash did not take. Watch the screen: if it never reaches the status display, install once more.
